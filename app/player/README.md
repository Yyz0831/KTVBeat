# KTVBeat 网页与本地服务

这是正式应用的播放器、上传接口和持久化任务队列。

运行 `node server.mjs`，打开 http://127.0.0.1:17862 。运行 `npm test` 执行 Node 自动检查。

完整使用说明、数据目录、模型及环境说明见 [应用说明](../README.md)。浏览器交互和试听步骤见 [浏览器验收](../浏览器验收.md)。

歌曲读取 `../data/library/` 中已提交的元数据，处理任务读取 `../data/jobs/`。播放过程使用准备好的三轨 FLAC 和歌词 JSON，不调用模型。上传后的后台处理由独立 Python 子进程串行完成。
